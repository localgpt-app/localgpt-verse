Actions that need a human

Two decisions only you can make

  1. Runtime verification with a real model. Everything above is verified compile/test/smoke — but without the 3.5 GB model, so the mistral.rs tool-calling loop and recipe generation have not been exercised live. Run scripts/fetch-bonsai.sh (bandwidth + disk), then cargo run --features llm and import a folder; watch the logs for llm: recipe for … and agent: session produced …. Or ask Claude to fetch and drive it — the download is the only human-scale resource.
  2. Model licensing before any distribution. Bonsai GGUF terms and the CLAP weights (CC-BY-NC) must be checked against your distribution model before shipping either tier in a release build. The app runs fully without them (rule-derived path), by design.
