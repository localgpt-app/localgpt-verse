  • Three real defects found & fixed along the way: (1) the fetch script’s pinned Q1_0 quant doesn’t parse in mistral.rs 0.8 → default is now the verified Q4_K_M; (2) the Q4_K_M doesn’t fit the CPU device map alongside the renderer → opt-in llm-metal feature; (3) mistral.rs 0.8’s grammar-constrained generate_structured hangs on GGUF even for a two-field schema → recipe generation is now plain instructed-JSON with a lenient balanced-object parse (serde defaults + clamped() + rule fallback keep every safety property), with a 180 s timeout. scripts/fetch-bonsai.sh · Cargo.toml · src/llm.rs
